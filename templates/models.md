# Model Tiers

Generated by Mahler from its defaults plus the `models` overrides in
`.harness/config.json`. Edit the overrides there, then rerun `mahler install`;
do not edit this file. The `delegate` skill explains how to choose a tier.

{{profiles}}

In Claude, launch the agent listed for the tier: Claude can't set effort at
launch. In Codex, spawn the profile's agent and pass the tier's model and
reasoning effort. A `skill:` or `agent:` entry hands the role to that skill or
agent type instead.
